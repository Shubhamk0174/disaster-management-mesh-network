# Prototypes & Experiments

This folder serves as an archive for older iterations, prototypes, and experimental versions of both the hardware code and the backend software.

## Purpose
During the development of the Disaster Management Mesh Network, multiple approaches were tested. This directory retains those earlier versions for reference, comparison, and historical context.

## Structure
- `/attempt2`, `/attempt3`, `/final`: Earlier stages of the Arduino hardware sketches.
- `/non_rescue_node`, `rescue_node.ino`: Original proofs-of-concept for the hardware roles before they were finalized and moved to the main `/hardware` directory.
- `/prototype-backend`: An initial version of the server infrastructure before transitioning to the final Prisma/Express implementation.

*Note: For the current, production-ready code, please refer to the main `/hardware` and `/backend` directories.*
