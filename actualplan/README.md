# Actual Plan & Architecture

This folder contains the core architectural documentation and protocol design for the Disaster Management Mesh Network.

## Purpose
Before writing the code, the system was fully architected to guarantee security, anonymity for relayed messages, and robust offline capabilities. These documents serve as the source of truth for the mesh protocol.

## Files
- `final_esp32_rescue_mesh_full_architecture.md`: The definitive guide. It explains the dual-key system (Ed25519 for authentication, X25519 for key agreement), the ChaCha20-Poly1305 encryption of the sensitive payload, and the concept of Normal Nodes vs. the Rescue Node.
- `mesh_rescue_architecture_complete.md`: A supplementary or earlier version of the architecture planning.

## Key Concepts
- **Offline First**: Devices do not require serial provisioning or internet.
- **Relay Anonymity**: Normal nodes route traffic without knowing the content of the payload (location/timestamp).
- **Hardcoded Provisioning**: Keys are generated by Python scripts and hardcoded into the C++ headers.
