# Architecture Presentations & Diagrams

This directory contains visual assets and diagrams used to explain the project.

## Contents
- **`.drawio` files**: Source files for draw.io (diagrams.net) flowcharts detailing the software architecture, the cryptographic data flow, and the hardware mesh topology.
- **`.png` / `.jpeg` files**: Rendered images of the hardware setups and software diagrams used in presentations, posters, or READMEs.

These diagrams visually demonstrate how the Normal Nodes interact with the Rescue Node and how the backend infrastructure integrates with the Next.js/React frontends.
