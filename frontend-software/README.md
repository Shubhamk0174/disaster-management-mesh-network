# Frontend Software (Vite/React)

This folder contains an alternative or legacy frontend application used for monitoring the disaster management network.

## Tech Stack
- **React**
- **Vite**
- **TypeScript**

## Purpose
Similar to the Next.js frontend, this application provides an interface for interacting with the backend data. It is located under the `v1` subdirectory, suggesting it may have been the initial version of the dashboard.

## Structure
- `/v1/src`: Contains the React components (`App.tsx`, `main.tsx`) and application logic.
- `/v1/index.html`: The HTML entry point.

## Setup
Navigate to the `v1` folder, run `npm install`, and use `npm run dev` to start the Vite development server.
